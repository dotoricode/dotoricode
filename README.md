# dotoricode

I build small AI office systems for solo builders.

Right now I'm turning Hermes Desktop into the operating room for my one-person company: agents, skills, memory, cron jobs, wiki notes, and mistake logs in one place.

## current focus

- Hermes Desktop as my AI office
- Korean and English writing that does not sound machine-made
- agent workflows that leave behind logs, files, diffs, tests, or status values
- small tools for people who mostly work alone

## main projects

- [hermes-desktop](https://github.com/dotoricode/hermes-desktop): the desktop office layer for my Hermes Agent setup
- [korean-humanizer](https://github.com/dotoricode/korean-humanizer): a Korean writing skill that removes the usual AI smell from generated text
- [cerberus](https://github.com/dotoricode/cerberus): a three-gate workflow for Claude Code: spec, plan, and intent
- [prompt-grill](https://github.com/dotoricode/prompt-grill): experiments around prompts, review, and better AI output
- [autonomous-flow-daemon](https://github.com/dotoricode/autonomous-flow-daemon): experiments in long-running autonomous agent workflows

## working style

I like tools that are boring, visible, and easy to check.

If an agent says it did something, I want a file, log, diff, test, or status value behind it.
